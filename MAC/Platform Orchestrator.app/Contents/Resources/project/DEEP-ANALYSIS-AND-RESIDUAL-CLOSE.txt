4. ГЛУБОКИЙ РАЗБОР ОСТАВШИХСЯ РИСКОВ
--------------------------------------------------------------------------------
4.1 OAuth e2e (код частично; live не доказан)
  Сделано: URI path, query params, token_saver.
  Осталось:
    - callback без Telegram auth (публичный redirect от Google/Meta)
    - опциональный alias /oauth/callback/* → webapp route
    - атомарность: account enabled только после успешного save токена
    - unit-тест с mock token exchange → файл tokens/*.json
  Риск без A: «OAuth в UI есть, токен на диск не попал / 401 на callback».

4.2 local_schedule due publish (КРИТИЧНО)
  Hold при schedule+no-media уже есть.
  Нужно: когда scheduled_for <= now и publish_mode=local_schedule
  (или external_id local-*), runner/scheduler должен вызвать IMMEDIATE publish,
  не снова «schedule hold».
  Иначе: слоты «на завтра» никогда не выйдут в сеть.
  Тест: FakeClock, EPS в прошлом → один цикл → published|error, не вечный scheduled.

4.3 Publisher exception / lease
  После reserve status=publishing; exception может оставить publishing до lease expiry.
  Нужно: retryable → ready/error + last_error + clear lease; permanent → error.
  Тест: module raises → не stuck publishing.

4.4 Единый token_provider
  StatusSync уже с helper-логикой; Publisher — через broker.
  Reconciliation / RemoteScan / Claims могут создавать module без того же пути.
  Вынести orchestrator/auth_tokens.py::get_access_token и подключить везде.

4.5 CI honesty
  check.sh: ruff || true — зелёный CI при lint fail.
  Часть тестов с assert True / or True ослабляет HARD_CUT доказательства.
  Исправить: ruff fail = fail (если установлен); запрет tautology в critical tests.

4.6 YAML duplicate keys
  facebook/instagram/… могут дублироваться; loader last-wins.
  Fail-closed + почистить example/ci.

4.7 Модель данных (не блокер YT+TG single-account)
  PK без account_id → multi-account Instagram на одну сущность невозможен.
  Для текущего HARD_CUT YT+TG одного канала — OK.
  Для «замена Postiz multi-account» — отдельный schema v21+ проект.

4.8 Ops-only (код не заменит)
  tokens/*.json, OAuth client secrets, ORCH_PUBLIC_BASE_URL + HTTPS
  STAGE_ACCEPTANCE: 1× YT + 1× TG live
  14 дней полевой прогон
  App Review Meta/TikTok, X tier, Rutube partner
