# Platform Orchestrator 8.6.0 — Stage Archive Index

The distribution contains four stage archives. Use them sequentially.

- **R0** — Integration: establish one real working provider operation on an owner-controlled test destination.
- **R1** — Review: submit only the minimum provider capability and scopes needed for the actual use case.
- **R2** — Correction: use only after a rejection; correct the specific blocker and preserve the same evidence trail.
- **R3** — Production: only after approval; add approved live accounts and perform one live canary before automation.

See `docs/release-stages/RELEASE-STAGES-2026-10-03.md` for the full stage map and each stage passport.
