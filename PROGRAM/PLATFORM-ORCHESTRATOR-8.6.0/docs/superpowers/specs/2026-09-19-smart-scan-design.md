# Умное сканирование папок (детекторы + рекурсия) — дизайн

Дата: 2026-09-19. Статус: утверждён пользователем, реализован.

## Цель
Пользователь добавляет одну главную папку (или несколько, включая папки шортсов) — оркестратор сам
находит серии, фильмы и шортсы по содержимому и раскладывает в очередь публикаций. Ничего
переименовывать не нужно; поддерживаются все текущие схемы и будущая (сериал → серия → соцсети).

## Правило регистрации
Строго «**маркеры + видео**»: папка регистрируется только когда есть и структурный маркер,
и готовое видео (стабильное 2 цикла подряд).

## Детекторы (по содержимому)
1. **Эпизод VideoMaker** — есть `<эпизод>/vertical/` или `wide/` (либо папки-платформы) и внутри
   видео. Даёт `long_videos` (широкий/вертикальный файл + `platform_paths`), плюс шортсы
   `shorts/short_XXX/` с мета (`*_title/_description/_hashtags/_hook/_upload.txt`, `*_cover.*`).
2. **Шортс Shorts Maker** — папка с `*_final.mp4` и мета-файлами рядом (`*_titles/_hooks/_hashtags`).
   Заголовок: первое поле «Заголовок:», описание: «Описание:», хук: первая строка хуков,
   хэштеги: первая строка, обложка: `*_final_cover.*`.
3. **Россыпь mp4** — mp4 с совпадающей метой рядом (`<stem>_title.txt` и т.п.).
4. **Сериал-папки** (аудио/сценарии/обложки/`готовые/`) не регистрируются сами — рекурсия
   находит серии внутри.

## Обход
Рекурсивный, глубина ≤ `watch_max_depth` (по умолчанию 5). Нашли эпизод/шортс — регистрируем и
внутрь не спускаемся (кроме `shorts/` внутри эпизода). Папка-корень сама может быть эпизодом.

## Мусор — игнор
Имена, начинающиеся с `.`, `_`, `._`; `$RECYCLE.BIN`, `System Volume Information`, `__pycache__`,
`*.app`, `*shorts_overflow*`. Папки без видео не регистрируются.

## Будущее: соцсети внутри эпизода
Папки `youtube/`, `telegram/`, `tiktok/`, … внутри эпизода (или рядом) → `platform_paths` записи.
Позже — на уровне серий; схема БД уже готова.

## Идемпотентность
Ключ `folder_path` (для россыпи: `<папка>::<файл>`). Повторный скан не дублирует.

## UI
- Кнопка «**+ Добавить эту папку**» (добавляет открытую папку в список сканирования).
- Корни обзора показываются реальными путями (`/mnt/ssd_src`, `/mnt/video`), переключатель.
- Сборка UI: b29.

## Конфиг
`watch_max_depth: 5` — предел глубины рекурсии.

## Тесты
Эпизод+шортсы, мета-парсинг, Shorts Maker (титлы/хуки/хэштеги/обложка), мусор и пустые папки,
platform-папки, корень = эпизод, идемпотентность.

## Известные ограничения
- Если одни и те же шортсы лежат и в пакете (`12/12/shorts/`), и рядом (`12/shorts/`), будут
  зарегистрированы оба набора — дубли публикаций. Рекомендация: держать один вариант.
- Для standalone-шортсов действует фильтр свежести (`max_age_days`).
- Скан зависит от доступности пути: если SSD отключён, корень просто пропускается (без удаления данных).
