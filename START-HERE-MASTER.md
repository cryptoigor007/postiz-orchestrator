# Platform Orchestrator 8.6.0 — Master staged distribution v2

This is the complete handoff package.

- `PROGRAM/PLATFORM-ORCHESTRATOR-8.6.0/` — full source program, including the tested macOS app at its root.
- `PROGRAM/*.zip` — standalone full-program archive.
- `MAC/Platform Orchestrator.app` — direct macOS double-click copy.
- `MAC/*.zip` — standalone macOS app archive.
- `STAGES/` — R0 → R1 → R2 → R3 stage archives.
- `DOCS/` — API/review guide, stage index, release report.
- `CHECKPOINT/` — rollback archive.
