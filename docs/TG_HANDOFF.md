## Как устроено

- **Ловит сообщения** бот внутри службы `orchestrator` на сервере (`TELEGRAM_MODE=poll`,
  `TELEGRAM_POLL_NO_ACK=1` — подтверждение Telegram не отправляется, поэтому сообщение
  не теряется никогда). Каждое входящее падает в надёжный ящик `inbox.jsonl`.
- **Читаем и отвечаем** инструментами из `~/orch-work/tools/`. Инструменты работают с Mac,
  токен берётся из локального `.env`.
- **Голосовые** расшифровываются: на Mac — MLX Whisper `large-v3-turbo` (тяжелее, точнее),
  на сервере резерв — faster-whisper `base` (`TG_VOICE_STT=1`), поэтому голосовые понятны
  даже когда Mac выключен.

## Готовые команды

```bash
# 1. Прочитать непрочитанное (ящик живёт на сервере)
ssh -o BatchMode=yes root@100.95.225.71 \
  'cd /opt/orchestrator && ./venv/bin/python tools/tg_inbox.py --unread'

# 2. Ответить владельцу и поставить 👍 ровно на те сообщения, на которые ответили
cd ~/orch-work
./venv/bin/python tools/tg_say.py --text-file /tmp/reply.txt --react 370
ssh -o BatchMode=yes root@100.95.225.71 \
  'cd /opt/orchestrator && ./venv/bin/python tools/tg_inbox.py --ack 370'

# 3. Сторож: запускать ФОНОМ (background job), ровно один
cd ~/orch-work && ./venv/bin/python tools/tg_voice.py --follow

# 4. Показать, что работа идёт: один раз и на долгую работу
cd ~/orch-work && ./venv/bin/python tools/tg_say.py --typing
cd ~/orch-work && ./venv/bin/python tools/tg_say.py --typing-for 1800   # тоже фоном

# 5. Картинка (сообщение уходит подписью)
cd ~/orch-work && ./venv/bin/python tools/tg_say.py --photo /tmp/shot.png --caption "подпись"

# 6. Голосовые вручную
cd ~/orch-work && ./venv/bin/python tools/tg_voice.py --unread --ack
```

`--chat` по умолчанию — владелец. Канал указывать только явно и только для настоящей
публикации: `--chat -1003882726633`.

## Правила, которые нарушать нельзя

1. Отвечать владельцу **только по-русски**.
2. 👍 ставить **строго на то сообщение, на которое ответил**. `--react-last` запрещён —
   только `--react <id> <id> …`.
3. Сообщение владельца **цитировать в чат дословно**, без пересказа.
4. В начале каждого хода и перед любой длинной работой — `--unread`; если что-то есть,
   сначала ответить владельцу, потом работать.
5. Сторож держать запущенным **всё время работы**. После каждого срабатывания — ответить
   и перезапустить. Перед завершением хода проверить, что он стоит.
6. Владелец должен видеть, что работа идёт: `--typing` перед долгой работой,
   `--typing-for` фоном на всю задачу. Молчание дольше пары минут — это ошибка.
7. Никаких фальшивых отметок «прочитано»: `--ack` и 👍 — только после реального ответа.
8. Не печатать секреты (токен бота, пароли кабинетов) в сообщениях и в чате.
