1. ЦЕЛЬ ПРОЕКТА
--------------------------------------------------------------------------------
Оркестратор контента: забирает готовые видео (VideoMaker/ShortsMaker), публикует
по расписанию на платформы (YouTube, Telegram, далее Instagram/TikTok/Facebook/
Threads), ведёт статусы и ссылки, управляется Telegram-ботом и панелью.
Текущий этап: перевод платформенных интеграций на МОДУЛЬНУЮ систему (стандарт 02).

--------------------------------------------------------------------------------

4) БД менять только аддитивно (ALTER TABLE), без переименований.
5) Никаких выдуманных фактов в доках: неизвестное помечать «проверить актуальность».
6) Новые решения — фиксировать в docs/dev/04_DECISIONS.txt (пункт + почему + тест).
7) Секреты — только .env (600)/брокер; в логах маскировать; в git не коммитить.
8) Честные capabilities в манифестах (bool; claims_check: auto|manual|unsupported).
9) Деплой на сервер — scripts/deploy.sh ТОЛЬКО после зелёных тестов и ревью.
