ПАКЕТ 2. Э2 — МОДУЛЬ YOUTUBE (эталон реализации, главный приоритет)
Файлы: src/orchestrator/platforms/youtube/{__init__.py, api.py, module.py,

2.1. api.py — клиент YouTube Data API v3 (Bearer; через общий HTTP-клиент ядра,
     ретраи/таймауты/маскирование — по 03_API_STANDARDS):
       - videos.insert: resumable upload (чанки), privacyStatus=private +
         status.publishAt (RFC3339) — отложка; videoId сохраняется СРАЗУ после
         финализации (до обложки);
       - thumbnails.set (jpg/png ≤ 2 МБ);
       - videos.update (title/description/categoryId/privacy — только разрешённое);
       - videos.delete; videos.list (part=status,processingDetails);
       - маппинг ошибок в таксономию ModuleErrorCode (MODULE_YOUTUBE.txt §10):
         401/403, quotaExceeded, uploadLimitExceeded, invalid_grant, 5xx →
         AUTH_REQUIRED/AUTH_EXPIRED/QUOTA/RATE_LIMIT/MEDIA_INVALID/
         PLATFORM_REJECTED/TRANSIENT/FATAL (сверься с src/orchestrator/platforms/
         base.py; retryable = TRANSIENT, RATE_LIMIT, AUTH_EXPIRED).
2.2. module.py — реализация контракта PlatformModule (см. platforms/base.py):
     prepare / upload / schedule_publish / publish / update_metadata / delete /
     get_status / check_claims (supported=false → ручной чекпойнт) / auth_status.
     Ошибка обложки не роняет публикацию (см. 1.3).

     путь оставить совместимым на переходный период). Авто-refresh без владельца;
     invalid_grant → понятный алерт. Тесты.
2.5. Ранняя загрузка daily_ahead: ежедневный джоб 09:00 держит «сегодня + завтра»

     дублей; проверка по entity_id/video_id). Квота 10000 units/сутки, upload ≈1600
