# План: Папки с типами, расписания по соцсетям, группы сетей (b30)

Дата: 2026-09-19. Статус: выполняется по чеклисту.

## Требования пользователя
1. В разделе «Папки» — отдельно выбирать **папку с сериалами** и **папку(и) с Shorts**.
2. Настройки постинга **по каждой соцсети отдельно** для:
   - серий (фильмов),
   - шортсов, нарезанных с серии (тематические),
   - произвольных шортсов на свободные темы (standalone).
3. Возможность **группировать соцсети**, чтобы постинг шёл **одновременно по таймеру**.

## Решения (v1)
- Настройки храним в БД (без деплоя): ключи `watch_roots` (новый формат),
  `schedule_settings`, `network_groups`. Legacy-форматы читаются.
- **Типы корней**: `auto` (как раньше), `series` (только серии), `shorts` (только шортсы).
- **Расписания**: `schedule_settings["<platform>"]` и `schedule_settings["group:<Name>"]`;
  группа имеет приоритет для входящих в неё платформ (одновременность = общее время).
- **Лимит постов/день**: переопределяется из UI для платформы (`daily_limit`).
- Валидация на сервере: дни недели, форматы времени HH:MM, лимиты 0..50.
- Совместимость: старые корни-строки → `auto`; отсутствие настроек → конфиг и дефолты.
